## 1. 문제 정의

### 무엇을, 왜 분석하는가

유튜브는 전 세계 크리에이터가 매 분 500시간 분량의 영상을 업로드하는 초경쟁 플랫폼이다. 대부분의 영상은 소수의 시청자에게만 도달하는 반면, 일부 영상은 알고리즘 추천을 타고 폭발적으로 확산(바이럴)된다. 본 프로젝트는 영상을 업로드하기 전 단계에서 수집 가능한 메타데이터(카테고리·태그 수·제목 길이·업로드 요일·시간대 등)만으로 해당 영상의 바이럴 가능성을 사전 예측하는 머신러닝 기반 웹 서비스를 구축하는 것을 목표로 한다. 이를 통해 크리에이터가 콘텐츠를 제작·발행하기 전에 전략적 의사결정(제목 수정, 업로드 시간 조정 등)을 내릴 수 있도록 지원한다.

### 예측 대상 (Target Variable)

| 항목 | 내용 | 비고 |
|------|------|------|
| 타겟 변수 | is_viral (이진 분류, 0/1) | Binary Classification |
| 바이럴 기준 | 조회수 상위 25% (75th percentile) 초과 여부 | ≈ 133만 뷰 이상 |
| 클래스 비율 | 바이럴 25% : 비바이럴 75% | 불균형 → 보정 적용 |

## 2. 데이터 소개 & EDA

### 데이터 규모 및 형식

| 항목 | 내용 |
|------|------|
| 행 수 | 161,470행 |
| 열 수 | 18개 원본 컬럼 + 파생 컬럼 (log_views, like_ratio, title_len 등) |
| 형식 | CSV (Kaggle 다운로드 → pandas로 로드) |
| 국가 | US / GB / CANADA / FRANCE — 각 약 4만 건으로 균등 분포 |
| 주요 컬럼 | video_id, views, likes, dislikes, comment_count, category_id, title, tags, published_at, trending_date |

### EDA에서 발견한 사실

*아래는 Streamlit EDA 페이지(pages/1_EDA.py)에서 도출한 주요 인사이트 3가지이다.*

#### ① 카테고리별 바이럴 비율 격차가 극명하다

> - Music 카테고리: 바이럴 비율 53.3%, 평균 조회수 약 822만 — 전 카테고리 중 압도적 1위
> - Entertainment: 전체 영상의 26%를 차지하나 바이럴 비율은 21.7%로 중간 수준
> - News & Politics: 바이럴 비율 6.8%로 최하위 — 단기 소비성 뉴스 콘텐츠의 특성 반영
> - Film & Animation: 적은 영상 수(9,139개)에도 바이럴 비율 33.2% — 예고편·클립의 팬덤 효과

#### ② 업로드 요일·시간대가 바이럴 확률에 유의미한 영향을 준다

> - 금요일(29.6%) · 목요일(28.7%) 업로드가 바이럴 비율 최고 → 주말 시청 급증 효과
> - 토요일(18.8%)이 가장 낮음 — 이미 주말이라 경쟁 영상이 많고 노출이 분산
> - UTC 새벽 4~5시 업로드가 바이럴 비율 최상위 (미국·영국 기준 전날 저녁 시간대와 일치)
> - 히트맵 분석 결과: 금요일 UTC 4시 조합이 바이럴 비율 63.3%로 전체 최고점

#### ③ 좋아요 수의 절대값이 비율보다 바이럴과 더 강하게 연관된다

> - Pearson 상관계수: likes(r=0.41) > views(r=0.35) — 좋아요가 조회수보다 바이럴과 더 높은 상관
> - 단, like_ratio(좋아요 비율) 상위 25% 영상의 바이럴 비율은 20.1%로 전체 평균(25%)보다 낮음
> - 결론: 절대적인 참여 수가 비율보다 중요 — 규모 큰 채널의 소규모 반응도 바이럴 요인

### 결측·이상치 처리

| 컬럼 | 처리 방법 | 근거 |
|------|----------|------|
| description | 결측 행 제거 또는 빈 문자열 대체 | 모델 입력 피처로 미사용 |
| tags | [none] 태그를 0개로 처리 → tag_count 파생 | 태그 수만 수치 피처로 활용 |
| views / likes 이상치 | log1p 변환(log_views) 적용 | 극단값 스케일 압축, 모델 안정성 향상 |
| **클래스 불균형** | XGBoost: scale_pos_weight=3 / RF·LR: class_weight='balanced' | EDA에서 확인한 25%:75% 불균형 보정 |

## 3. 특성 엔지니어링

### 새로 만든 파생 피처

EDA 분석 결과를 바탕으로, 업로드 전에도 알 수 있는 정보만으로 구성된 파생 피처를 설계하였다. 후처리 지표(likes, comment_count)는 데이터 리크 우려로 직접 입력 피처에서 제외하고, 모델 학습 시 참고용으로만 활용한다.

| 파생 피처 | 계산 방법 | 근거 (EDA 인사이트) |
|----------|----------|-------------------|
| like_ratio | likes / (views + 1) | 좋아요 비율 — 단독 신호는 약하나 다른 피처와 결합 시 유효 |
| tag_count | tags.split('\|').len() | 바이럴 영상 평균 19개 vs 비바이럴 15개 — 4개 차이 |
| title_len | len(title) | 바이럴 평균 47자 vs 비바이럴 51자 — 짧은 제목이 소폭 유리 |
| log_views | log1p(views) | 조회수 분포 정규화 — 학습 안정성 및 모델 수렴 향상 |
| publish_hour | published_at.hour (UTC) | UTC 4~5시가 바이럴 비율 최상위 (히트맵 분석) |
| is_weekend | 요일 ∈ {토, 일} → 1 | 토요일 바이럴 비율 18.8%로 최하위 — 주말 게시 패널티 |
| category_id | 원본 ID 그대로 사용 (Label Enc.) | 카테고리 간 바이럴 비율 차이 6.8%~53.3%로 가장 강력한 피처 |
| comments_disabled | boolean → 0/1 | 댓글 비활성화 시 알고리즘 engagement 신호 감소 |

> ⚠ **데이터 리크 주의**: likes, comment_count, dislikes는 업로드 이후 집계되는 값 — 예측 서비스 입력에서 제외
>
> ✅ **입력 피처(INPUT_FEATURE_COLS)** = like_ratio, tag_count, title_len, category_id, is_weekend, publish_hour, comments_disabled, ratings_disabled

## 4. 모델 / 서비스

### 사용한 방법 및 선택 이유

본 프로젝트는 정형 데이터(tabular) 기반의 이진 분류 문제이므로, 딥러닝보다 해석 가능성과 학습 속도가 우수한 ML 앙상블 모델을 1차로 선택하였다. 세 가지 모델(Logistic Regression · Random Forest · XGBoost)을 동일 조건에서 비교하여 최종 서비스 모델을 결정하였다.

### 모델 성능 비교

| 모델 | 정확도 (Accuracy) | F1 (weighted) | ROC-AUC |
|------|-----------------|---------------|---------|
| Logistic Regression | 0.8835 | 0.8877 | 0.9563 |
| Random Forest | 0.9828 | 0.9827 | 0.9979 |
| **XGBoost ★ (최종 서비스)** | 0.9686 | 0.9689 | 0.9955 |

*※ ★ 표시 모델이 예측 서비스에 사용됨. 수치는 Streamlit 3_모델_서비스.py 실행 결과로 기입.*

### 입력 → 출력 흐름

| 입력 (업로드 전 메타데이터) | 출력 |
|--------------------------|------|
| 카테고리 / 태그 수 / 제목 길이 / 예상 좋아요 비율 / 업로드 요일 / 업로드 시각(UTC) / 댓글·좋아요 활성화 여부 | 바이럴 확률 (0~100%) / 바이럴 여부 (0/1) / 예상 조회수 범위 / 항목별 개선 피드백 |

*클래스 불균형 보정: EDA에서 확인한 25%:75% 비율을 보정하기 위해 XGBoost에 scale_pos_weight=3 적용. Random Forest와 Logistic Regression에는 class_weight='balanced' 사용.*

## 6. 결론 & 한계

### 알게 된 것

- 카테고리가 단일 피처 중 가장 강력한 바이럴 예측 신호임을 실증하였다 (Music 53.3% vs News 6.8%).
- 업로드 타이밍(요일·시각)이 콘텐츠 내용과 무관하게 바이럴 확률에 최대 3배 차이를 만든다.
- 좋아요 비율(like_ratio)보다 절대적인 좋아요 수(likes)가 바이럴과 더 강하게 연관된다 (r=0.41 vs 0.35).
- 클래스 불균형(25:75) 보정 없이는 모델이 비바이럴만 예측하는 trivial classifier로 수렴할 수 있음을 확인하였다.
- Streamlit 멀티페이지 앱으로 EDA → 시각화 → 예측 서비스까지 일관된 데이터 스토리를 구성할 수 있었다.

### 아쉬운 점 / 향후 과제

- **데이터 리크 위험:** likes·comment_count는 업로드 이후 집계값이므로 업로드 전 예측 서비스의 현실 적용성이 제한됨. 업로드 후 1시간 데이터만 활용하는 설정이 필요하다.
- **텍스트 피처 미활용:** 제목 키워드·감정 분석(BERT/RoBERTa 임베딩)을 피처로 추가하면 예측력을 추가로 높일 수 있다.
- **썸네일 품질 미반영:** 바이럴에 큰 영향을 주는 썸네일 이미지(CNN 기반 품질 점수)를 피처에 포함하지 못하였다.
- **시간적 분포 고려 부재:** 데이터가 특정 기간에 집중되어 있어 최신 알고리즘 변화(Shorts 도입 등)를 반영하지 못한다.
- **데이터 규모의 한계:** 약 16만 건의 데이터는 머신러닝 모델 학습에 충분하지 않을 수 있으며, 더 많은 데이터를 확보할수록 모델의 일반화 성능을 높일 수 있다. 특히 카테고리·국가별 세분화 분석 시 일부 구간에서 샘플 수가 부족해 통계적 신뢰도가 낮아질 수 있다.
- **구독자 수 데이터 부재:** 동일 콘텐츠도 채널 규모에 따라 초기 노출이 크게 달라지나 YouTube Data API 연동이 필요해 포함하지 못하였다.
